# Forma — Interactive Pricing Cards

Open index.html in any modern browser. No installation, build step, or internet connection is required.

Files: index.html (structure), styles.css (responsive styling), script.js (interactions).

Implemented assignment requirements:
- Four cards with icons, titles, descriptions, prices, feature lists, and CTA buttons.
- Monthly/yearly switch updates every price; yearly billing saves 20% and shows the annual total.
- All / Basic / Premium category filtering. Billing selection survives filtering.
- Hover lift, shadow, border transitions, and button press animations.
- Most Popular badge on Pro.
- Responsive CSS Grid: four, two, and one column layouts.
- Active filter states and interactive plan selection dialog.
- Keyboard controls, focus indicators, live status updates, and reduced-motion support.

Prices are sample USD values. CTA buttons open a demonstration confirmation; no backend, payment processing, or real subscription is included or required by the assignment.

Enhanced version: Team-size slider (1–50), plan selection state, live cost statistics, annual cost comparison bars, CSV estimate download, feature comparison table, expandable FAQs, and calculator reset. All statistics are calculated estimates from sample prices, not real customer analytics. Chart rows select the plan for the calculator.
